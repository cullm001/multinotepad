Visit: [multinotepad.pages.dev](https://multinotepad.pages.dev)

A free and private online notepad that works right in your browser. Create multiple notes, organize them into folders, and format your text — all without creating an account.

## Features

### Notes Management
- Create unlimited notes — Write as many notes as you want
- Rich text formatting — Bold, italic, underline, lists, colors, fonts, and more
- Auto-save — Your notes save automatically as you type
- Word and character counter — Real-time count as you write

### Organization
- Folder management — Create folders to organize your notes
- Drag and drop — Move notes between folders and reorder them
- Search notes — Search across titles and content
- View counts — See note and folder counts at a glance

### Theme and UI
- Dark and Light mode — Switch between themes instantly
- Collapsible sidebar — More space for writing
- Responsive design — Works on desktop, tablet, and mobile
- Popout window — Write in a separate floating window

### Privacy
- 100% local storage — All notes stay on your device
- No cloud upload — Your data never leaves your browser
- No account needed — Just open the page and start writing
- Persistent storage — Notes survive browser restarts


## Technologies Used

- HTML5
- CSS3 
- Vanilla JavaScript
- LocalStorage API


## Privacy Statement

MultiNotePad stores all data locally in your browser's LocalStorage. No data is ever sent to any server. Your notes are 100% private and stay on your device.
